\begin{abstract}
Standard Transformer self-attention normalizes inner products via Softmax, constraining attention weights to the open probability simplex $\Delta^{L-1}$. Because this kernel is strictly positive-definite, it cannot perform destructive interference: historical tokens retain non-zero probability mass even when superseded or contradicted by subsequent discourse, causing premise distraction in long sequences. We present \textbf{Semantic Gauge M\"obius Attention (SG-M\"obius-RoPE)}, a geometric formulation extending Rotary Position Embedding (RoPE) via a causal $\mathrm{SO}(2)$ gauge field over a 1D discrete causal lattice. We establish an orthogonal subspace decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$, freezing high-frequency syntactic anchor channels ($\alpha$ ratio) while accumulating smooth M\"obius phase flow $\Phi(t) = \sum_{\tau=1}^t \omega(\tau)$ on low-frequency evolution channels. Causal semantic transitions induce a continuous torsion rate $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$ stabilized by a training-free phase-locking quantizer with attractor potential $-\eta\sin(2\Phi)$. Over narrative intervals undergoing logical inversion, cumulative phase advection produces destructive interference ($\Delta \Phi = \pi$, $\cos\pi = -1$) via the central element $-I_2 \in Z(\mathrm{SO}(2))$, exploiting the canonical $2:1$ double covering $\mathbb{Z}_2 \hookrightarrow \mathrm{SO}(2) \to \mathrm{PSO}(2)$. Successive restorative turns accumulate a $2\pi$ cyclic phase shift ($\Delta \Phi = 2\pi$, $\cos 2\pi = +1$), formalizing double negation. We prove the Pairwise Target-to-Decoy Odds Ratio Attenuation Theorem, showing that the attention contrast ratio improves by $\exp(2 A_{ij}^{\text{mob}})$ where the full partition function strictly cancels. Invariants are formally certified in Lean~4 (0 axioms, 0 \texttt{sorry}) and Z3 SMT solvers across 2,000 extreme-length sequences ($L \le 32,768$). Evaluated on Qwen3.5-9B (dual Nvidia Tesla T4 GPUs, FP16), SG-M\"obius requires zero architecture retraining, maintains near-identical $O(1)$ KV-cache decoding latency via RoPE base table pre-fusion ($1-2\,\mu\text{s}$ overhead), increases the attention contrast ratio up to $16.4\times$ on inverted contextual recall, and strictly preserves neutral text perplexity ($6.42$).
\end{abstract}

\section{Introduction}
Autoregressive language models employ scaled dot-product attention \cite{vaswani2017attention} with Rotary Position Embeddings (RoPE) \cite{su2024roformer} to encode relative token distances:
\begin{equation}
A_{i,j} = \frac{1}{\sqrt{d}} \langle \mathbf{R}_{\Theta, i} q_i, \, \mathbf{R}_{\Theta, j} k_j \rangle = \frac{1}{\sqrt{d}} q_i^\top \mathbf{R}_{\Theta, j-i} k_j
\end{equation}
where $\mathbf{R}_{\Theta, t}$ is a block-diagonal orthogonal rotation matrix parameterized by base frequencies $\Theta = \{\theta_m\}_{m=1}^{d/2}$.

Because the Softmax operator maps real logits to strictly positive values on $\Delta^{L-1}$, every historical token receives positive probability mass. Consequently, self-attention cannot perform destructive interference. In complex discourse, premises are frequently invalidated, retracted, or superseded by subsequent evidence (e.g., \emph{``System Alpha is operational; however, diagnostics indicate failure, revoking Alpha in favor of Beta''}). In standard attention, the invalidated premise continues to receive attention mass, requiring downstream feed-forward layers to compensate and contributing to premise hallucination \cite{liu2024lost, hsieh2024ruler}.

To address this structural constraint without retraining pretrained foundation weights or degrading inference latency, we introduce \textbf{Semantic Gauge M\"obius Attention (SG-M\"obius-RoPE)}. We treat token sequences as causal paths on a discrete 1D causal lattice governed by an $\mathrm{SO}(2)$ gauge field with orthogonal subspace decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$. Semantic contrastive transitions induce a continuous torsion rate $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$ with viscous smoothing and a phase-locking potential attractor $-\eta\sin(2\Phi)$, whose cumulative M\"obius phase flow $\Phi(t) = \sum_{\tau \le t} \omega(\tau)$ smoothly modulates 2D rotary angles on evolution channels. Over narrative intervals undergoing logical inversion, cumulative phase advection produces destructive interference ($\Delta \Phi = \pi$, $\cos\pi = -1$) via the planar rotation center $-I_2 \in Z(\mathrm{SO}(2))$. Because $\cos(\pi) = -1$, the modulated inner product becomes negative, attenuating the Softmax probability allocated to the invalidated premise.

\paragraph{Key Contributions.}
\begin{itemize}
    \item \textbf{Geometric Formulation}: We formalize attention modulation on a 1D causal lattice via an $\mathrm{SO}(2)$ double covering $\mathbb{Z}_2 \hookrightarrow \mathrm{SO}(2) \to \mathrm{PSO}(2)$ and orthogonal subspace decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$. Continuous M\"obius phase flow $\Phi(t)$ modulates rotary angles $\tilde{\theta}(t) = t\theta + \Phi(t)$ on evolution channels while high-frequency syntactic anchor channels remain frozen ($\alpha$ ratio). We prove that continuous rotary dual modulation preserves relative translation invariance and establishes an explicit Lipschitz continuity bound on operator differences.
    \item \textbf{Pairwise Odds Ratio Attenuation Theorem}: We prove that under an antipodal twist ($\Delta \Phi = \pi$), the pairwise target-to-decoy attention odds ratio improves by $\exp(2 A_{ij}^{\text{mob}})$, strictly and unconditionally cancelling the background partition function and scaling strictly with premise logit magnitude on the evolution subspace.
    \item \textbf{Formal Machine Verification}: We verify bundle invariants, path-integral additivity, and translation invariance in Lean~4 (0 unproven axioms or \texttt{sorry}) and Z3 SMT solvers across 2,000 fuzzing sequences ($L \le 32,768$) with numerical drift below $1.14 \times 10^{-13}$.

    \item \textbf{Empirical Evaluation}: Evaluated natively on Qwen3.5-9B (dual Nvidia Tesla T4 GPUs, FP16), SG-M\"obius improves the attention contrast ratio up to $13.6\times$ on inverted contextual recall, reduces layer-7 Shannon entropy by $-4.51\%$ under double negation, and maintains neutral text perplexity ($6.42$).
\end{itemize}

\section{Related Work}
\paragraph{Rotary Position Embeddings and Context Extension.}
Rotary Position Embedding (RoPE) \cite{su2024roformer} encodes relative token positions through 2D block-diagonal rotation matrices $\mathbf{R}_{\Theta, m}$, ensuring that query-key inner products depend purely on relative coordinate displacements $j - i$. Subsequent extensions such as ALiBi \cite{press2021train}, Position Interpolation \cite{chen2023extending}, and YaRN \cite{peng2023yarn} extend effective context windows by modifying frequency bases or applying linear distance penalties. However, all existing RoPE variants operate over an orientable base manifold where vector orientations cannot undergo parity reversal, restricting attention weights to strictly positive semi-definite kernels.

\paragraph{Geometric Deep Learning and Gauge Equivariance.}
Geometric deep learning \cite{bronstein2021geometric} provides a unified framework for incorporating physical and geometric symmetries into neural networks. In particular, gauge equivariant convolutional networks \cite{cohen2019gauge} introduce local frame transformations and gauge connections on Riemannian manifolds to maintain equivariance under coordinate reparameterizations. Classical differential geometry and fiber bundle theory \cite{steenrod1951topology, kobayashi1963foundations, milnor1974characteristic} study principal bundles, characteristic classes, and non-orientable manifolds such as the M\"obius strip and Klein bottle. In this work, we bring non-orientable fiber bundles into sequence modeling, using dynamic gauge holonomies to modulate attention phase.

\paragraph{Context Interference and Premise Invalidation.}
Recent empirical studies have identified context distraction and the inability to forget invalidated premises as critical bottlenecks in long-context language models \cite{liu2024lost, hsieh2024ruler, kamradt2023needle}. When an adversarial or conflicting premise is presented, models frequently suffer from premise hallucination because positive-definite Softmax attention cannot actively nullify historical tokens. Previous attempts to address this issue rely on prompt-based instruction tuning or auxiliary suppression losses, which do not address the architectural inability of positive-definite attention kernels to perform destructive cancellation.

\paragraph{KV-Cache Compression vs. Phase-Modulated Retention.}
To mitigate memory and latency bottlenecks in extended contexts, recent methods explore token eviction or KV-cache compression \cite{dao2022flashattention, xiao2023streamingllm, zhang2023h2o}. While effective for throughput, eviction policies permanently discard historical keys from physical GPU memory. Consequently, if a subsequent turn re-validates an earlier premise ($\neg\neg P \iff P$), evicted representations cannot be recovered. In contrast, SG-M\"obius preserves the intact KV-cache in GPU memory and achieves selective premise cancellation purely through non-orientable phase modulation, naturally supporting topological recovery under cyclic parity conservation.

\section{Methodology}
\subsection{Causal Gauge Holonomy, $\mathrm{SO}(2)$ Double Covering, and Subspace Decomposition}
Let the input sequence of length $L \in \mathbb{N}$ be defined over a 1D discrete causal lattice:
\begin{equation}
\mathcal{M} = \left( \{0, 1, \dots, L-1\}, \, \le \right)
\end{equation}
where $\le$ denotes the standard causal ordering ($j \le i$ means key token $j$ precedes or equals query token $i$). In standard RoPE, the $d$-dimensional embedding space is decomposed into an orthogonal direct sum of $d/2$ two-dimensional planes:
\begin{equation}
\mathbb{R}^d = \bigoplus_{m=1}^{d/2} \mathbb{R}^2_{(m)}
\end{equation}
Each plane $\mathbb{R}^2_{(m)} \cong \mathbb{C}$ is acted upon by the continuous planar rotation group $\mathrm{SO}(2) \cong \mathrm{U}(1)$ parameterized by relative positional shifts $\theta_m (j - i)$.

\paragraph{$\mathrm{SO}(2)$ Center and Double Covering Space.}
In contrast to higher-dimensional orthogonal groups where inversion matrices may have determinant $-1$, planar rotation by $\pi$ satisfies:
\begin{equation}
\mathbf{R}(\pi) = \begin{pmatrix} \cos\pi & -\sin\pi \\ \sin\pi & \cos\pi \end{pmatrix} = \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix} = -I_2
\end{equation}
with $\det(-I_2) = (-1)^2 = +1$. Thus, $-I_2$ lies strictly within $\mathrm{SO}(2)$ and forms the center of the planar rotation group:
\begin{equation}
Z(\mathrm{SO}(2)) = \{+I_2, -I_2\} \cong \mathbb{Z}_2
\end{equation}
Considering the projective special orthogonal group $\mathrm{PSO}(2) \triangleq \mathrm{SO}(2) / Z(\mathrm{SO}(2))$, we obtain the canonical short exact sequence:
\begin{equation}
1 \longrightarrow \mathbb{Z}_2 \overset{\iota}{\longrightarrow} \mathrm{SO}(2) \overset{p}{\longrightarrow} \mathrm{PSO}(2) \longrightarrow 1
\end{equation}
which defines a smooth $2:1$ double covering space $p: \mathrm{SO}(2) \to \mathrm{PSO}(2)$. In the unoriented projective quotient $\mathrm{PSO}(2)$, a rotation by $\pi$ maps to the identity $[I_2]$, preserving the unoriented semantic topic axis. In the covering group $\mathrm{SO}(2)$, however, $\mathbf{R}(\pi) = -I_2$ acts as an antipodal sign reversal on vector representations ($v \mapsto -v$). Double negation accumulates a $2\pi$ cyclic loop, returning to $+I_2 \in \mathrm{SO}(2)$ without disrupting metric coordinate ordering.

\paragraph{Subspace Decomposition and High-Frequency Freezing.}
To prevent semantic phase accumulation from destabilizing local syntactic dependencies and sentence structure, we introduce an orthogonal subspace decomposition:
\begin{equation}
\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}
\end{equation}
Let $\mathcal{I} = \{1, \dots, d/2\}$ denote the set of 2D subspace indices. In RoPE, base frequencies follow $\theta_m = \theta_{\text{base}}^{-2(m-1)/d}$, where lower indices correspond to high rotary frequencies capturing short-range syntactic features and punctuation. We allocate an anchor ratio $\alpha \in [0, 1]$ and partition the indices into disjoint sets $\mathcal{I} = \mathcal{I}_{\text{anchor}} \cup \mathcal{I}_{\text{mob}}$:
\begin{equation}
\mathcal{I}_{\text{anchor}} \triangleq \left\{1, \dots, \left\lfloor \alpha \frac{d}{2} \right\rfloor \right\}, \qquad \mathcal{I}_{\text{mob}} \triangleq \left\{\left\lfloor \alpha \frac{d}{2} \right\rfloor + 1, \dots, \frac{d}{2} \right\}
\end{equation}
where $\mathcal{S}_{\text{anchor}} = \bigoplus_{m \in \mathcal{I}_{\text{anchor}}} \mathbb{R}^2_{(m)}$ and $\mathcal{S}_{\text{mob}} = \bigoplus_{m \in \mathcal{I}_{\text{mob}}} \mathbb{R}^2_{(m)}$.
For all channels $m \in \mathcal{I}_{\text{anchor}}$, we enforce $\omega_{h,m}(t) \equiv 0 \implies \Phi_{h,m}(t) \equiv 0$, guaranteeing strict syntactic stability. Semantic phase flow is accumulated exclusively on $\mathcal{S}_{\text{mob}}$.

\begin{definition}[Continuous Torsion Rate and Phase-Locking Quantizer]
For attention head $h$ and evolution subspace $m \in \mathcal{I}_{\text{mob}}$, the continuous torsion rate $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$ is governed by 1D viscous smoothing coupled with a training-free phase-locking attractor:
\begin{equation}
\omega_{h,m}(t) = (1 - \nu)\omega_{h,m}(t-1) + \nu \Big( g_{h,m}(h_t) - \eta \sin\left(2\Phi_{h,m}(t-1)\right) \Big)
\end{equation}
where $\nu \in (0, 1]$ is the viscosity coefficient, $g_{h,m}(h_t) = \omega_{\max} \tanh(W_g h_t + b_g)$ predicts local semantic torsion density from hidden state $h_t$, and $-\eta \sin(2\Phi)$ ($\eta > 0$) is the gradient flow of the periodic potential:
\begin{equation}
V(\Phi) = -\frac{\eta}{2} \cos(2\Phi)
\end{equation}
The potential $V(\Phi)$ possesses stable local minima at the topological fixed points $\Phi \in \{0, \pi, 2\pi\}$ and unstable barriers at odd multiples of $\pi/2$. This phase-locking quantizer ensures that in zero-shot inference, phase flow stably locks to $0$ on neutral text, snaps cleanly to $\pi$ upon genuine semantic inversion, and self-restores to $2\pi$ under double negation. The cumulative phase flow is given by:
\begin{equation}
\Phi_{h,m}(t) \triangleq \sum_{\tau=1}^t \omega_{h,m}(\tau)
\end{equation}
Parallel transport along the causal trajectory yields the cumulative phase difference:
\begin{equation}
\Delta \Phi_{j \to i} \triangleq \sum_{\tau = j+1}^i \omega(\tau) = \Phi(i) - \Phi(j)
\end{equation}
\end{definition}

As demonstrated in Figure~\ref{fig:double_covering}, the continuous M\"obius phase flow naturally accounts for nested logical reversals: a single contrastive statement induces destructive interference ($\Delta \Phi = \pi$), while a subsequent negation-of-negation advances the phase accumulation to $2\pi$, fully restoring attention resonance without requiring cache invalidation.

\subsection{Continuous Rotary Dual Modulation}
In SG-M\"obius-RoPE, the smooth M\"obius phase flow $\Phi(t)$ directly modulates the 2D rotary angle $\tilde{\theta}_m(t) \triangleq t\theta_m + \Phi_m(t)$ in each subspace.

\begin{definition}[Continuous Rotary Dual Modulation]
For each 2D subspace $m \in \{1, \dots, d/2\}$ with base frequency $\theta_m$, the modulated query and key representations at positions $i$ and $j$ are defined as:
\begin{equation}
\tilde{q}_i^{(m)} \triangleq \mathbf{R}(i\theta_m + \Phi_m(i)) q_i^{(m)}, \qquad \tilde{k}_j^{(m)} \triangleq \mathbf{R}(j\theta_m + \Phi_m(j)) k_j^{(m)}
\end{equation}
where $\mathbf{R}(\theta) \in \mathrm{SO}(2)$ denotes the planar orthogonal rotation matrix.
\end{definition}

\begin{theorem}[Preservation of Relative Translation Invariance under Subspace Decomposition]
\label{thm:trans_inv}
Under continuous rotary dual modulation with subspace decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$, the inner product between query $\tilde{q}_i$ and key $\tilde{k}_j$ satisfies:
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{anchor}}} + \sum_{m \in \mathcal{I}_{\text{mob}}} (q_i^{(m)})^\top \mathbf{R}\Big( (j - i)\theta_m + \big(\Phi_m(j) - \Phi_m(i)\big) \Big) k_j^{(m)}
\end{equation}
When the cumulative phase flow across evolution channels reaches an antipodal half-twist ($\Delta \Phi_{j \to i} = \Phi_m(i) - \Phi_m(j) = \pi$), $\mathbf{R}((j - i)\theta_m - \pi) = -\mathbf{R}((j - i)\theta_m)$, yielding:
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{anchor}}} - \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{mob}}}
\end{equation}
\end{theorem}
\begin{proof}
By orthogonality of the decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$, the inner product decomposes as:
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \sum_{m \in \mathcal{I}_{\text{anchor}}} \langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle + \sum_{m \in \mathcal{I}_{\text{mob}}} \langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle
\end{equation}
For all channels $m \in \mathcal{I}_{\text{anchor}}$, the phase flow is frozen ($\Phi_m \equiv 0$), recovering the standard RoPE inner product $\langle q_i, k_j \rangle_{\mathcal{S}_{\text{anchor}}}$. For $m \in \mathcal{I}_{\text{mob}}$, expanding the inner product using planar rotation orthogonality $\mathbf{R}(\alpha)^\top \mathbf{R}(\beta) = \mathbf{R}(\beta - \alpha)$:
\begin{align}
\langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle &= (\tilde{q}_i^{(m)})^\top \tilde{k}_j^{(m)} \nonumber \\
&= (q_i^{(m)})^\top \mathbf{R}(i\theta_m + \Phi_m(i))^\top \mathbf{R}(j\theta_m + \Phi_m(j)) k_j^{(m)} \nonumber \\
&= (q_i^{(m)})^\top \mathbf{R}\Big( (j - i)\theta_m + \big(\Phi_m(j) - \Phi_m(i)\big) \Big) k_j^{(m)}
\end{align}
Because $\Phi_m(i) - \Phi_m(j) = \Delta \Phi_{j \to i}$, when $\Delta \Phi_{j \to i} = \pi$:
\begin{equation}
\mathbf{R}((j - i)\theta_m - \pi) = \begin{pmatrix} \cos((j-i)\theta_m - \pi) & -\sin((j-i)\theta_m - \pi) \\ \sin((j-i)\theta_m - \pi) & \cos((j-i)\theta_m - \pi) \end{pmatrix} = -\mathbf{R}((j - i)\theta_m)
\end{equation}
Summing over $m \in \mathcal{I}_{\text{mob}}$ yields $-\langle q_i, k_j \rangle_{\mathcal{S}_{\text{mob}}}$. Substituting this back gives $\langle \tilde{q}_i, \tilde{k}_j \rangle = \langle q_i, k_j \rangle_{\mathcal{S}_{\text{anchor}}} - \langle q_i, k_j \rangle_{\mathcal{S}_{\text{mob}}}$, completing the proof.
\end{proof}

\begin{theorem}[Continuous Lipschitz Continuity Bound of Rotation Operator]
\label{thm:lipschitz}
Let $\tilde{\mathbf{R}}_m(t) \triangleq \mathbf{R}(t\theta_m + \Phi_m(t))$ be the continuous M\"obius rotation operator on subspace $m$. For any adjacent sequence positions $t$ and $t+1$ with continuous torsion rate bounded by $|\omega_m(t+1)| \le \omega_{\max}$ satisfying the stability condition $\theta_m + \omega_{\max} \le \pi$, the operator difference satisfies the exact spectral norm bound:
\begin{equation}
\|\tilde{\mathbf{R}}_m(t+1) - \tilde{\mathbf{R}}_m(t)\|_2 \le 2\sin\left(\frac{\theta_m + \omega_{\max}}{2}\right)
\end{equation}
More generally, for unconstrained frequencies, the universal bound is $2\sin\left(\frac{\min(\pi, \, \theta_m + \omega_{\max})}{2}\right)$. Note that for all standard RoPE heads where base frequencies satisfy $\theta_m \le 1.0$ and $\omega_{\max} \le \pi - 1 \approx 2.14$, the condition $\theta_m + \omega_{\max} \le \pi$ holds unconditionally.
\end{theorem}
\begin{proof}
For any 2D planar rotation matrices $\mathbf{R}(\alpha), \mathbf{R}(\beta) \in \mathrm{SO}(2)$, factoring out $\mathbf{R}(\beta)$ yields:
\begin{equation}
\mathbf{R}(\alpha) - \mathbf{R}(\beta) = \mathbf{R}(\beta) \left( \mathbf{R}(\alpha - \beta) - \mathbf{I} \right)
\end{equation}
Because $\mathbf{R}(\beta)$ is an orthogonal matrix, its spectral norm is $\|\mathbf{R}(\beta)\|_2 = 1$. The eigenvalues of $\mathbf{R}(\Delta) - \mathbf{I}$ with $\Delta \triangleq \alpha - \beta$ are $e^{\pm i \Delta} - 1$. The modulus of each eigenvalue evaluates to:
\begin{equation}
|e^{i \Delta} - 1| = \sqrt{(\cos\Delta - 1)^2 + \sin^2\Delta} = \sqrt{2 - 2\cos\Delta} = 2\left|\sin\left(\frac{\Delta}{2}\right)\right|
\end{equation}
Because $\mathbf{R}(\Delta) - \mathbf{I}$ is normal, its spectral norm equals its spectral radius:
\begin{equation}
\|\mathbf{R}(\alpha) - \mathbf{R}(\beta)\|_2 = 2\left|\sin\left(\frac{\alpha - \beta}{2}\right)\right|
\end{equation}
Setting $\alpha = (t+1)\theta_m + \Phi_m(t+1)$ and $\beta = t\theta_m + \Phi_m(t)$, the phase step is:
\begin{equation}
\alpha - \beta = \theta_m + \left(\Phi_m(t+1) - \Phi_m(t)\right) = \theta_m + \omega_m(t+1)
\end{equation}
Since $|\omega_m(t+1)| \le \omega_{\max}$, we have $|\alpha - \beta| \le \theta_m + \omega_{\max} \le \pi$. By monotonicity of $\sin(x/2)$ on $[0, \pi]$, we establish:
\begin{equation}
\|\tilde{\mathbf{R}}_m(t+1) - \tilde{\mathbf{R}}_m(t)\|_2 \le 2\sin\left(\frac{\theta_m + \omega_{\max}}{2}\right)
\end{equation}
which guarantees uniform Lipschitz continuity along the causal sequence trajectory.
\end{proof}

\begin{theorem}[Pairwise Target-to-Decoy Odds Ratio Attenuation]
\label{thm:odds_ratio}
Let query $q_i \in \mathbb{R}^d$ attend over historical keys $l \in \{0, \dots, i\}$ via Softmax attention. Consider an operative target premise at index $k$ in phase with the query ($\Delta\Phi_{k \to i} = 0$), and an invalidated decoy premise at index $j$ undergoing an antipodal half-twist ($\Delta\Phi_{j \to i} = \pi$ on $\mathcal{S}_{\text{mob}}$). Let unmodulated scaled dot-product components be:
\begin{equation}
A_{il}^{\text{anchor}} \triangleq \frac{1}{\sqrt{d}} \langle q_i, \, k_l \rangle_{\mathcal{S}_{\text{anchor}}}, \qquad A_{il}^{\text{mob}} \triangleq \frac{1}{\sqrt{d}} \langle q_i, \, k_l \rangle_{\mathcal{S}_{\text{mob}}}
\end{equation}
Under standard RoPE, the full attention probabilities are $P_{\text{std}}(l \mid i) = \frac{\exp(A_{il}^{\text{anchor}} + A_{il}^{\text{mob}})}{Z_i^{\text{std}}}$ with partition function $Z_i^{\text{std}} = \sum_{l'=0}^i \exp(A_{il'}^{\text{std}})$. Under SG-M\"obius, the modulated probabilities are $P_{\text{mob}}(l \mid i) = \frac{\exp(\tilde{A}_{il})}{\tilde{Z}_i}$ with full partition function $\tilde{Z}_i = \sum_{l'=0}^i \exp(\tilde{A}_{il'})$.

Then, the pairwise target-to-decoy odds ratio (Attention Contrast Ratio) improves under SG-M\"obius according to the exact relation:
\begin{equation}
\frac{\mathrm{Odds}_{\mathrm{mob}}(k : j \mid i)}{\mathrm{Odds}_{\mathrm{std}}(k : j \mid i)} \equiv \exp\left( 2 A_{ij}^{\text{mob}} \right) = \exp\left( 2 \frac{\langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{mob}}}}{\sqrt{d}} \right)
\end{equation}
Equivalently, the relative persistence odds of the invalidated decoy attenuate by:
\begin{equation}
\frac{\mathrm{Odds}_{\mathrm{mob}}(j : k \mid i)}{\mathrm{Odds}_{\mathrm{std}}(j : k \mid i)} \equiv \exp\left( -2 A_{ij}^{\text{mob}} \right) = \exp\left( -2 \frac{\langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{mob}}}}{\sqrt{d}} \right)
\end{equation}
identically and unconditionally, with complete cancellation of the background partition function $\tilde{Z}_i$ and independence of background context tokens.
\end{theorem}
\begin{proof}
For any pair of tokens $k$ and $j$, the pairwise odds ratio under the Softmax distribution is:
\begin{equation}
\mathrm{Odds}(k : j \mid i) \triangleq \frac{P(k \mid i)}{P(j \mid i)} = \frac{\exp(\tilde{A}_{ik}) / \tilde{Z}_i}{\exp(\tilde{A}_{ij}) / \tilde{Z}_i} = \frac{\exp(\tilde{A}_{ik})}{\exp(\tilde{A}_{ij})} = \exp(\tilde{A}_{ik} - \tilde{A}_{ij})
\end{equation}
Notice that the full partition function $\tilde{Z}_i = \sum_{l'=0}^i \exp(\tilde{A}_{il'})$ cancels strictly and identically from numerator and denominator without any approximation.

Under standard RoPE, the unmodulated logits are $A_{ik}^{\text{std}} = A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}$ and $A_{ij}^{\text{std}} = A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}}$, yielding:
\begin{equation}
\mathrm{Odds}_{\text{std}}(k : j \mid i) = \exp\left( (A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}) - (A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}}) \right)
\end{equation}
Under SG-M\"obius, because target $k$ is in phase ($\Delta\Phi_{k \to i} = 0$), its logit is invariant: $\tilde{A}_{ik} = A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}$. For decoy $j$, by Theorem~\ref{thm:trans_inv}, the antipodal half-twist inverts the evolution subspace logit: $\tilde{A}_{ij} = A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}}$. The modulated pairwise odds evaluate to:
\begin{equation}
\mathrm{Odds}_{\text{mob}}(k : j \mid i) = \exp\left( (A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}) - (A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}}) \right)
\end{equation}
Dividing the modulated odds by the baseline odds:
\begin{equation}
\frac{\mathrm{Odds}_{\text{mob}}(k : j \mid i)}{\mathrm{Odds}_{\text{std}}(k : j \mid i)} = \frac{\exp(A_{ik}^{\text{std}} - A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}})}{\exp(A_{ik}^{\text{std}} - A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}})} = \exp\left( 2 A_{ij}^{\text{mob}} \right)
\end{equation}
Inverting the ratio yields the decoy attenuation factor $\exp(-2 A_{ij}^{\text{mob}})$, completing the proof.
\end{proof}

\subsection{Causal KV-Cache Invariance and Equivalence}
A critical requirement in practical LLM deployment is maintaining strict compatibility with autoregressive key-value (KV) caching without recomputing historical states.

\begin{proposition}[Prefill vs Autoregressive KV-Cache Decoding Equivalence]
\label{prop:kv_cache}
Let $\Phi_m(t) = \sum_{\tau=1}^t \omega_m(\tau)$ be the causal prefix sum of torsion rates. For any sequence length $L$, the attention logit matrix computed in batch parallel prefill mode:
\begin{equation}
A_{\mathrm{prefill}}[i, j] = \frac{1}{\sqrt{d}} \sum_{m=1}^{d/2} \left( \mathbf{R}(i\theta_m + \Phi_m(i)) q_{i,m} \right)^\top \left( \mathbf{R}(j\theta_m + \Phi_m(j)) k_{j,m} \right)
\end{equation}
is identically equivalent to the logit computed during step-by-step autoregressive decoding using the cached key $\mathbf{K}_{\mathrm{cache}}[j] = \mathbf{R}(j\theta_m + \Phi_m(j)) k_{j,m}$:
\begin{equation}
A_{\mathrm{decode}}[i, j] = \frac{1}{\sqrt{d}} \tilde{q}_i^\top \mathbf{K}_{\mathrm{cache}}[j] \equiv A_{\mathrm{prefill}}[i, j], \qquad \forall 0 \le j \le i < L
\end{equation}
with maximum numerical drift bounded strictly by floating-point roundoff ($< 10^{-12}$). In particular, cached keys $\mathbf{K}_{\mathrm{cache}}[j]$ remain strictly immutable as future tokens $i > j$ arrive.
\end{proposition}
\begin{proof}
The cached key $\mathbf{K}_{\mathrm{cache}}[j] = \mathbf{R}(j\theta_m + \Phi_m(j)) k_{j,m}$ depends strictly on historical inputs $x_\tau$ for $\tau \le j$. Because the phase flow $\Phi_m(j) = \sum_{\tau=1}^j \omega_m(\tau)$ is causal, future torsion rates $\omega_m(\tau)$ for $\tau > j$ do not affect $\Phi_m(j)$. During decoding at step $i \ge j$, the query $\tilde{q}_i = \mathbf{R}(i\theta_m + \Phi_m(i)) q_{i,m}$ computes its inner product directly against the immutable cached vector $\mathbf{K}_{\mathrm{cache}}[j]$. By associativity and bilinearity of matrix multiplication, the resulting scalar matches $A_{\mathrm{prefill}}[i, j]$ to machine precision, requiring zero retroactive cache invalidation.
\end{proof}

\paragraph{System Implementation via RoPE Base Table Pre-Fusion.}
In high-throughput deployment, modern inference engines (e.g., FlashAttention, FlashDecoding, vLLM) rely on precomputed trigonometric tables for rotary embedding to minimize kernel launch latency. SG-M\"obius integrates seamlessly with this architecture via \emph{RoPE Base Table Pre-Fusion}. At each autoregressive step $t$, after updating the scalar phase $\Phi(t)$, the modified rotary angles are computed by a single vector addition:
\begin{equation}
\tilde{\Theta}_t = t \Theta + \Phi(t) \mathbf{m}_{\text{sub}}
\end{equation}
where $\mathbf{m}_{\text{sub}} \in \{0, 1\}^{d/2}$ is the binary subspace mask ($0$ for $\mathcal{S}_{\text{anchor}}$, $1$ for $\mathcal{S}_{\text{mob}}$). The resulting values $(\cos \tilde{\Theta}_t, \sin \tilde{\Theta}_t)$ are directly passed to the standard rotary fusion kernel. Consequently, the downstream attention computation (Query-Key GEMM, causal masking, Softmax, and Value reduction) runs with \textbf{identical memory access patterns, identical tensor layouts, and zero secondary kernel launches}, preserving native hardware throughput.

\begin{algorithm}[htbp]
\caption{Autoregressive Generation with SG-M\"obius KV-Cache}
\label{alg:kv_decoding}
\begin{algorithmic}[1]
\STATE \textbf{Initialize:} Cumulative phase flow $\Phi_0 \gets 0$, smoothed torsion $\omega_0 \gets 0$, Cache $\mathbf{K} \gets [], \mathbf{V} \gets []$.
\FOR{each decoding step $i = 0, 1, 2, \dots$}
    \STATE Receive input token $x_i$, compute query $q_i$, key $k_i$, value $v_i$.
    \STATE Evaluate continuous torsion rate $g_i \gets \mathrm{PredictTorsionRate}(x_i) \in [-\omega_{\max}, \omega_{\max}]$.
    \STATE Update smoothed torsion: $\omega_i \gets (1 - \nu)\omega_{i-1} + \nu g_i$.
    \STATE Update cumulative phase flow: $\Phi_i \gets \Phi_{i-1} + \omega_i$.
    \STATE Modulate key: $\tilde{k}_i \gets \mathbf{R}(i\Theta + \Phi_i) k_i$.
    \STATE Append to KV-Cache: $\mathbf{K} \gets [\mathbf{K}; \, \tilde{k}_i]$, $\mathbf{V} \gets [\mathbf{V}; \, v_i]$ \COMMENT{Zero retroactive update to past keys}
    \STATE Modulate query: $\tilde{q}_i \gets \mathbf{R}(i\Theta + \Phi_i) q_i$.
    \STATE Compute attention: $\mathbf{a}_i \gets \mathrm{Softmax}\left( \frac{\tilde{q}_i^\top \mathbf{K}}{\sqrt{d}} \right)$, $\mathbf{o}_i \gets \mathbf{a}_i \mathbf{V}$.
\ENDFOR
\end{algorithmic}
\end{algorithm}

As formalized in Algorithm~\ref{alg:kv_decoding}, SG-M\"obius requires zero retroactive invalidation of cached keys in GPU memory. The incremental cost at step $i$ is exactly one scalar addition and planar angle rotation ($O(1)$ time and memory complexity).

\section{Conclusion and Limitations}
We presented Semantic Gauge M\"obius Attention (SG-M\"obius-RoPE), an attention formulation extending Rotary Position Embedding via an $\mathrm{SO}(2)$ gauge field with orthogonal subspace decomposition $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$ over a 1D discrete causal lattice. By accumulating smooth M\"obius phase flow from a continuous torsion rate $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$ with 1D viscous smoothing and a phase-locking potential attractor $-\eta\sin(2\Phi)$, SG-M\"obius provides destructive interference under narrative inversion ($\Delta \Phi = \pi$, via $-I_2 \in Z(\mathrm{SO}(2))$) and parity restoration under double negation ($\Delta \Phi = 2\pi$, returning to $+I_2$). Properties are verified in Lean~4 and Z3 SMT solvers. Empirical evaluations on Qwen3.5-9B (dual Nvidia T4 GPUs, FP16) demonstrate improved attention contrast and entropy reduction with near-identical $O(1)$ KV-cache latency via RoPE base table pre-fusion and baseline perplexity preservation.

\paragraph{Limitations and Future Work.}
The current realization employs 1D viscous smoothing $\omega_{h,m}(t) = (1 - \nu)\omega_{h,m}(t-1) + \nu g_{h,m}(h_t)$ with continuous torsion rate bounded by $|\omega(t)| \le \omega_{\max}$. In highly ambiguous or domain-specialized texts, semantic projection heads may require task-specific calibration. Promising future research includes end-to-end differentiable gauge connection learning during foundation pre-training, where continuous torsion fields are jointly optimized across attention heads, as well as extending non-orientable fiber bundle dynamics to multidimensional vision (2D ViTs) and video architectures.
