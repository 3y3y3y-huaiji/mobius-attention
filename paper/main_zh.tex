\begin{abstract}
标准 Transformer 自注意力机制通过开概率单纯形 $\Delta^{L-1}$ 上的严格正 Softmax 算子对内积进行归一化。在 pre-Softmax logits 中缺乏选择性子空间符号反转机制的情况下，历史 token 即使被后续语篇废弃、推翻或反驳，仍会保留未衰减的内积贡献，从而导致长序列中的前提干扰（premise distraction）与幻觉。我们提出\textbf{子空间反相 RoPE（SG-M\"obius-RoPE）}，一种通过因果正交子空间相位调制扩展旋转位置编码（RoPE）的注意力形式体系。借鉴声学主动降噪（Active Noise Cancellation, ANC）原理，模型在低频演化通道上引入反相载波，同时冻结高频句法锚点通道（$\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$）。因果语义转折诱导连续相位角速度 $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$，其累积未约束相位 $\bar{\Phi}(t) = \sum_{\tau=1}^t \omega(\tau)$ 经免训练锁相量化器 $\Phi(t) = \bar{\Phi}(t) - \eta\sin(2\bar{\Phi}(t))$ 整形。在经历逻辑反转的叙事区间内，累积相移达到 $\pi$，在 pre-Softmax logits 中产生精确破坏性符号反转（$\mathbf{R}(\theta - \pi) = -\mathbf{R}(\theta)$），且完全不影响 KV-Cache 不变性。随后的恢复性转折累积 $2\pi$ 循环相移（$\cos 2\pi = +1$），形式化双重否定律复原。我们严格证明了条件成对目标-诱饵优势比衰减定理，确立在相干演化子空间对齐（$A_{ij}^{\text{mob}} > 0$）下，单头成对优势比按 $\exp(2A_{ij}^{\text{mob}})$ 缩放，且注意力头配分函数在分子分母中严格精确抵消。所有代数不变量与扫描程序等价性已在 Lean~4（0 公理，0 \texttt{sorry}）以及 Z3 SMT 求解器中跨 2,000 条极限长序列（$L \le 32,768$）完成形式化机器证明。在 Qwen3.5-9B（双 Nvidia Tesla T4 GPU，FP16）上的评测表明，SG-M\"obius 无需架构重训，通过尾部角度融合保持近乎恒定的 $O(1)$ KV-Cache 解码时延（单层算子开销仅 $+1.8\sim 2.1\,\mu\text{s}$），在多尺度上下文扩展中实现全尺度稳定大于 1.0 倍的失效诱饵注意力物理压制（$1.13\times\sim 1.90\times$，全程大于 $1.0\times$），注意力对比度 ACR 最高提升 $+465.1\%$（$L=1,116$ 时自 $3.62\to 20.44$；$L=18,030$ 时压制比 $1.34\times$，ACR 提升 $+88.5\%$，单头峰值对比优势比放大达 $16.4\times$（具体为第 7 层第 4 个头，Layer~7, Head~4）），并在真实门控激活下严格保持中性文本困惑度（$7.48$，$0.0\%$ 退化）。
\end{abstract}

\section{引言 (Introduction)}
自回归大语言模型普遍采用缩放点积注意力 \cite{vaswani2017attention} 与旋转位置编码（RoPE）\cite{su2024roformer} 来编码 token 间的相对距离：
\begin{equation}
A_{i,j} = \frac{1}{\sqrt{d}} \langle \mathbf{R}_{\Theta, i} q_i, \, \mathbf{R}_{\Theta, j} k_j \rangle = \frac{1}{\sqrt{d}} q_i^\top \mathbf{R}_{\Theta, j-i} k_j
\end{equation}
其中 $\mathbf{R}_{\Theta, t}$ 是由基频集合 $\Theta = \{\theta_m\}_{m=1}^{d/2}$ 参数化的分块对角正交旋转矩阵。

由于 Softmax 算子将实数 logits 严格映射到开单纯形 $\Delta^{L-1}$ 内部的正值区间，历史序列中的每个 token 都必然分配到正的概率质量。因此，标准自注意力机制在数学上无法实现破坏性相消干涉。在复杂的逻辑推理与长对话中，前提经常被后续事实废除、撤回或推翻（例如：\emph{“Alpha 系统运行正常；然而最新诊断报告确认严重故障，现废止 Alpha 方案并启用 Beta 方案”}）。在标准注意力中，已失效的前提仍持续吸引大量注意力权重，迫使下游前馈网络消耗容量进行代偿，导致严重的前提幻觉与上下文干扰 \cite{liu2024lost, hsieh2024ruler}。

为了在无需重新训练基座权重且不降低推理吞吐的前提下解决该结构性缺陷，我们提出了\textbf{子空间反相 RoPE（SG-M\"obius-RoPE）}，如图~\ref{fig:intro_teaser} 所示。借鉴主动降噪（ANC）原理，我们将嵌入空间分解为正交直和 $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$。语义对比转折诱导连续相位角速度 $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$，结合 1D 粘性平滑与锁相势能投影 $-\eta\sin(2\bar{\Phi})$，其累积的相位流 $\Phi(t)$ 平滑调制演化通道上的 2D 旋转角（图~\ref{fig:curvature}）。在经历逻辑反转的区间上，累积相移产生破坏性相消干涉（$\Delta \Phi = \pi$，$\cos\pi = -1$），通过平面二维旋转符号反转 $\mathbf{R}(\theta - \pi) = -\mathbf{R}(\theta)$ 将调制后的内积转为负值，在任意反转坐标处均能主动衰减分配给失效前提的 Softmax 概率（图~\ref{fig:arbitrary_heatmap}）。

\paragraph{主要贡献。}
\begin{itemize}
    \item \textbf{子空间反相形式化体系}：我们通过正交子空间分解 $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$ 与平面反相旋转 $\mathbf{R}(\theta - \pi) = -\mathbf{R}(\theta)$ 形式化了注意力调制。连续相位流 $\Phi(t)$ 调制演化通道上的旋转角 $\tilde{\theta}(t) = t\theta + \Phi(t)$，同时高频句法锚点通道保持冻结（比例 $\alpha$）。我们证明了连续旋转对偶调制保持相对平移不变性，并给出了明确的算子差分 Lipschitz 连续性上界。
    \item \textbf{条件成对优势比衰减定理}：严格证明了在反相半周（$\Delta \Phi = \pi$）和演化子空间相干对齐（$A_{ij}^{\text{mob}} > 0$）下，单头成对目标与诱饵的注意力优势比按 $\exp(2 A_{ij}^{\text{mob}})$ 放缩，且在注意力头内部严格消除了背景配分函数。
    \item \textbf{形式化机器证明}：在 Lean~4 交互式定理证明器中完成两级并行关联扫描程序等价性、前缀和可加性与相移不变性的无公理证明（0 公理，0 \texttt{sorry}），并在 Z3 SMT 求解器中跨 2,000 条长序列（$L \le 32,768$）完成代数验证，数值漂移低于 $1.14 \times 10^{-13}$。
    \item \textbf{KV-Cache 完全兼容}：调制后的 Key 向量 $\tilde{k}_j = \mathbf{R}(j\Theta + \Phi(j)\mathbf{m}_{\text{sub}}) k_j$ 严格仅依赖历史 token $\tau \le j$，在后续推理步中无需对已缓存数据执行任何追溯修改，严格保持 $O(1)$ 的单步解码吞吐。
    \item \textbf{真实模型评测}：在 Qwen3.5-9B（双 Nvidia Tesla T4 GPU，FP16）上跨 $L=545 \sim 18,030$ tokens 进行全面评测，实现全尺度一致大于 1.0 倍的诱饵注意力物理压制（$1.13\times\sim 1.90\times$，全程大于 $1.0\times$），多头注意力对比度 ACR 最高提升 $+465.1\%$（$L=1,116$ 时由 $3.62\to 20.44$；$L=18,030$ 时压制比 $1.34\times$，ACR 提升 $+88.5\%$，单头峰值优势比放大达 $16.4\times$），注意力香农熵随上下文容量平稳扩展，并在真实门控激活下严格保全了中性文本困惑度（$7.48$，$0.0\%$ 衰减）。
\end{itemize}

\section{相关工作 (Related Work)}
\paragraph{旋转位置编码与上下文扩展。}
旋转位置编码（RoPE）\cite{su2024roformer} 通过 2D 分块对角正交旋转矩阵 $\mathbf{R}_{\Theta, m}$ 编码相对距离，确保 Query-Key 内积纯粹依赖于相对坐标差 $j - i$。随后的 ALiBi \cite{press2021train}、位置插值（Position Interpolation）\cite{chen2023extending} 和 YaRN \cite{peng2023yarn} 通过微调基准频率或施加线性距离衰减来扩展上下文窗口。然而，所有现存 RoPE 变体均基于固定的坐标算子，其 pre-Softmax logits 无法根据局部语义变化在特定子空间上执行选择性符号反转。

\paragraph{注意力中的相位调制与主动信号相消。}
几何深度学习 \cite{bronstein2021geometric} 提供了将物理与几何对称性融合进神经网络的统一框架。在信号处理领域，主动降噪（ANC）通过产生与噪声源反相（$180^\circ$ 或 $\pi$ 相移）的抵消波实现破坏性相消。现有 RoPE 拓展方法 \cite{press2021train, chen2023extending, peng2023yarn} 仅通过调整基频或引入距离衰减扩展窗口，缺乏 pre-Softmax logits 的符号反转机制。本文在旋转位置编码的正交子空间中引入因果相位调制，通过反相载波在语义转折处对已失效前提进行选择性破坏相消。

\paragraph{上下文干扰与前提失效。}
近年来的实证研究发现，长上下文大语言模型普遍面临上下文干扰以及无法遗忘失效前提的关键瓶颈 \cite{liu2024lost, hsieh2024ruler, kamradt2023needle}。当遇到对抗性或冲突性的前置前提时，由于严格正的 Softmax 无法主动相消历史 token，模型极易产生前提幻觉。既有方案依赖于 Prompt 指令微调或辅助抑制损失，未能解决自注意力架构本身缺乏 pre-Softmax 破坏性子空间相消机制的问题。

\paragraph{KV-Cache 驱逐 vs. 相位调制保留。}
为了缓解长文本下的显存与时延瓶颈，现有技术探索了 token 驱逐与 KV-Cache 压缩机制 \cite{dao2022flashattention, xiao2023streamingllm, zhang2023h2o}。尽管能提升吞吐，驱逐策略会从 GPU 物理显存中永久丢弃历史 Key。一旦后续叙事重新肯定了先前的论点（$\neg\neg P \iff P$），被驱逐的表征便无法召回。相比之下，SG-M\"obius 将完整的 KV-Cache 保留在显存中，纯粹通过反相相位调制实现选择性相消，天然支持双重否定律下的拓扑复原。

\section{方法体系 (Methodology)}
\subsection{因果相位流、主动降噪（ANC）类比与子空间分解}
设输入序列长度为 $L \in \mathbb{N}$，定义在 1D 离散因果索引集上：
\begin{equation}
\mathcal{M} = \left( \{0, 1, \dots, L-1\}, \, \le \right)
\end{equation}
其中 $\le$ 表示标准的因果偏序（$j \le i$ 表示 Key token $j$ 处于 Query token $i$ 之前或同位置）。在标准 RoPE 中，$d$ 维嵌入空间被分解为 $d/2$ 个相互正交的 2 维平面的直和：
\begin{equation}
\mathbb{R}^d = \bigoplus_{m=1}^{d/2} \mathbb{R}^2_{(m)}
\end{equation}
每个平面 $\mathbb{R}^2_{(m)} \cong \mathbb{C}$ 由相对位置位移 $\theta_m (j - i)$ 参数化的平面连续旋转群 $\mathrm{SO}(2) \cong \mathrm{U}(1)$ 作用。

\paragraph{平面二维旋转反转与主动降噪（ANC）类比。}
标准 RoPE 采用平面二维旋转矩阵 $\mathbf{R}(\theta) \in \mathrm{SO}(2)$ 作用于 Query 与 Key 向量。关键在于，平面内旋转 $\pi$ 角度实现精确的符号反转：
\begin{equation}
\mathbf{R}(\pi) = \begin{pmatrix} \cos\pi & -\sin\pi \\ \sin\pi & \cos\pi \end{pmatrix} = \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix} = -I_2
\end{equation}
注意 $\det(-I_2) = (-1)^2 = +1$，因此 $-I_2$ 属于保向正交旋转。通过在位置载波 $(j - i)\theta_m$ 上叠加累积相移 $\Delta\Phi = \pi$，可得：
\begin{equation}
\mathbf{R}\big((j - i)\theta_m - \pi\big) = -\mathbf{R}\big((j - i)\theta_m\big)
\end{equation}
该机制在物理上与声学\emph{主动降噪（Active Noise Cancellation, ANC）}高度类比：通过在语义演化频段生成反相载波（$\pi$ 相位差），使内积发生破坏性符号翻转。在 pre-Softmax logit 空间中，原本的正内积被转化为负值，驱动 Softmax 分配的注意力概率呈指数级迅速衰减。随后的“否定之否定”叙事引入额外的 $\pi$ 相移（$\Delta\Phi = 2\pi$），由 $\mathbf{R}\big((j - i)\theta_m - 2\pi\big) = +\mathbf{R}\big((j - i)\theta_m\big)$ 无损恢复初始前提的注意力共振，无需追溯修改任何 KV-Cache。

\paragraph{子空间分解与高频句法锚点冻结。}
为防止语义相位的累积破坏局部句法依赖与句子结构，我们引入正交子空间分解：
\begin{equation}
\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}
\end{equation}
记 $\mathcal{I} = \{1, \dots, d/2\}$ 为 2D 子空间索引集。在 RoPE 中，基频遵循 $\theta_m = \theta_{\text{base}}^{-2(m-1)/d}$，其中较小的通道索引对应极高旋转频率，用于捕捉局部短程句法与标点。我们设定锚点比例 $\alpha \in [0, 1]$，将索引划分为互斥集合 $\mathcal{I} = \mathcal{I}_{\text{anchor}} \cup \mathcal{I}_{\text{mob}}$：
\begin{equation}
\mathcal{I}_{\text{anchor}} \triangleq \left\{1, \dots, \left\lfloor \alpha \frac{d}{2} \right\rfloor \right\}, \qquad \mathcal{I}_{\text{mob}} \triangleq \left\{\left\lfloor \alpha \frac{d}{2} \right\rfloor + 1, \dots, \frac{d}{2} \right\}
\end{equation}
其中 $\mathcal{S}_{\text{anchor}} = \bigoplus_{m \in \mathcal{I}_{\text{anchor}}} \mathbb{R}^2_{(m)}$，$\mathcal{S}_{\text{mob}} = \bigoplus_{m \in \mathcal{I}_{\text{mob}}} \mathbb{R}^2_{(m)}$。
对于所有锚点通道 $m \in \mathcal{I}_{\text{anchor}}$，强制约束 $\omega_{h,m}(t) \equiv 0 \implies \Phi_{h,m}(t) \equiv 0$，保证句法绝对稳定性；相位流仅在演化子空间 $\mathcal{S}_{\text{mob}}$ 上累积。

\begin{definition}[连续相位角速度、语篇语义探测器与免训练锁相量化器]
对于注意力头 $h$ 与演化子空间通道 $m \in \mathcal{I}_{\text{mob}}$，因果连续相位角速度 $\omega_{h,m}(t) \in [-\omega_{\max}, \omega_{\max}]$ 遵循 1 维粘性平滑流：
\begin{equation}
\omega_{h,m}(t) = (1 - \nu)\omega_{h,m}(t-1) + \nu g_{h,m}(h_t), \quad \bar{\Phi}_{h,m}(t) \triangleq \sum_{\tau=1}^t \omega_{h,m}(\tau)
\end{equation}
其中 $\nu \in (0, 1]$ 为粘度系数。语义转折探测器 $g_{h,m}(h_t)$ 为完全免训练算子，由预训练反嵌入矩阵（Unembedding Matrix）$U \in \mathbb{R}^{V \times d}$ 中反转类语篇标记集合 $\mathcal{V}_{\text{rev}}$（如 \emph{however}, \emph{nevertheless}, \emph{revoke}）与顺承标记集合 $\mathcal{V}_{\text{cont}}$ 的均值差分正规化方向向量构造：$w_g \triangleq \frac{\mu_{\text{rev}} - \mu_{\text{cont}}}{\|\mu_{\text{rev}} - \mu_{\text{cont}}\|_2} \in \mathbb{R}^d$。为确保在中性常态语篇（如 WikiText-103）上零误触，探测器引入硬死区门限 $\tau_{\text{gate}} > 0$：
\begin{equation}
z_t \triangleq w_g^\top h_t + b_g, \qquad g_{h,m}(h_t) \triangleq \omega_{\max} \cdot \mathrm{softsign}\Big(\mathrm{ReLU}\big(|z_t| - \tau_{\text{gate}}\big) \cdot \mathrm{sgn}(z_t)\Big)
\end{equation}
在普通叙事文本中 $|z_t| < \tau_{\text{gate}}$，恒有 $g(h_t) \equiv 0 \implies \omega(t) \equiv 0$，从而在数学上恒等保全基线文本困惑度（$7.48$，$0.0\%$ 退化）。
当经历明确的语义废止转折（$|z_t| \ge \tau_{\text{gate}}$）触发相移时，有效旋转相位 $\Phi_{h,m}(t)$ 采用周期势能 $V(\bar{\Phi}) = -\frac{\eta}{2}\cos(2\bar{\Phi})$（$\eta \in [0, \tfrac{1}{2}]$）导出的逐点无记忆阶梯投影：
\begin{equation}
\Phi_{h,m}(t) \triangleq \bar{\Phi}_{h,m}(t) - \eta\sin\!\big(2\bar{\Phi}_{h,m}(t)\big)
\end{equation}
在默认的多头相干配置下，头 $h$ 内的所有演化通道共享相同的角速度轨迹与相位 $\Phi_h(t)$。两点间相对因果相移为：
\begin{equation}
\Delta\Phi_{j\to i}^{(m)} \triangleq \Phi_m(i) - \Phi_m(j)
\end{equation}
\end{definition}

\subsection{连续旋转对偶调制与数学定理}
在 SG-M\"obius-RoPE 中，平滑相位流 $\Phi(t)$ 直接调制每个子空间的 2D 旋转角 $\tilde{\theta}_m(t) \triangleq t\theta_m + \Phi_m(t)$。

\begin{definition}[连续旋转对偶调制]
对于每个 2D 子空间 $m \in \{1, \dots, d/2\}$，带有相位调制的 Query 与 Key 向量定义为：
\begin{equation}
\tilde{q}_i^{(m)} \triangleq \mathbf{R}(i\theta_m + \Phi_m(i)) q_i^{(m)}, \qquad \tilde{k}_j^{(m)} \triangleq \mathbf{R}(j\theta_m + \Phi_m(j)) k_j^{(m)}
\end{equation}
其中 $\mathbf{R}(\theta) \in \mathrm{SO}(2)$ 为平面旋转矩阵。记 $\mathcal{S}_{\text{anchor}}$ 与 $\mathcal{S}_{\text{mob}}$ 上的基底 RoPE 内积为：
\begin{align}
\langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{anchor}}}^{\mathrm{RoPE}} &\triangleq \sum_{m \in \mathcal{I}_{\text{anchor}}} (q_i^{(m)})^\top \mathbf{R}\big((j - i)\theta_m\big) k_j^{(m)}, \\
\langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{mob}}}^{\mathrm{RoPE}} &\triangleq \sum_{m \in \mathcal{I}_{\text{mob}}} (q_i^{(m)})^\top \mathbf{R}\big((j - i)\theta_m\big) k_j^{(m)}
\end{align}
\end{definition}

\begin{theorem}[子空间分解下的相对位置保持与相移不变性]
\label{thm:trans_inv}
在连续旋转对偶调制与子空间分解 $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$ 下，Query $\tilde{q}_i$ 与 Key $\tilde{k}_j$ 的内积仅严格依赖于相对位移 $j - i$ 与相对因果相移 $\Delta \Phi_{j \to i}^{(m)} = \Phi_m(i) - \Phi_m(j)$：
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{anchor}}}^{\mathrm{RoPE}} + \sum_{m \in \mathcal{I}_{\text{mob}}} (q_i^{(m)})^\top \mathbf{R}\Big( (j - i)\theta_m + \big(\Phi_m(j) - \Phi_m(i)\big) \Big) k_j^{(m)}
\end{equation}
当演化通道上的累积相移达到反相半周（$\Delta \Phi_{j \to i}^{(m)} = \pi$）时，$\mathbf{R}((j - i)\theta_m - \pi) = -\mathbf{R}((j - i)\theta_m)$，产生严格的演化子空间符号反转：
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{anchor}}}^{\mathrm{RoPE}} - \langle q_i, \, k_j \rangle_{\mathcal{S}_{\text{mob}}}^{\mathrm{RoPE}}
\end{equation}
\end{theorem}
\begin{proof}
由子空间分解的正交性，全内积等于各子空间内积之和：
\begin{equation}
\langle \tilde{q}_i, \, \tilde{k}_j \rangle = \sum_{m \in \mathcal{I}_{\text{anchor}}} \langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle + \sum_{m \in \mathcal{I}_{\text{mob}}} \langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle
\end{equation}
对于所有 $m \in \mathcal{I}_{\text{anchor}}$，由于相位冻结（$\Phi_m \equiv 0$），退化为标准 RoPE 内积 $\langle q_i, k_j \rangle_{\mathcal{S}_{\text{anchor}}}^{\mathrm{RoPE}}$。对于 $m \in \mathcal{I}_{\text{mob}}$，利用平面旋转正交性 $\mathbf{R}(\alpha)^\top \mathbf{R}(\beta) = \mathbf{R}(\beta - \alpha)$：
\begin{align}
\langle \tilde{q}_i^{(m)}, \, \tilde{k}_j^{(m)} \rangle &= (\tilde{q}_i^{(m)})^\top \tilde{k}_j^{(m)} \nonumber \\
&= (q_i^{(m)})^\top \mathbf{R}(i\theta_m + \Phi_m(i))^\top \mathbf{R}(j\theta_m + \Phi_m(j)) k_j^{(m)} \nonumber \\
&= (q_i^{(m)})^\top \mathbf{R}\Big( (j - i)\theta_m + \big(\Phi_m(j) - \Phi_m(i)\big) \Big) k_j^{(m)}
\end{align}
由于 $\Phi_m(i) - \Phi_m(j) = \Delta \Phi_{j \to i}^{(m)}$，相对旋转角为 $(j - i)\theta_m - \Delta \Phi_{j \to i}^{(m)}$。当 $\Delta \Phi_{j \to i}^{(m)} = \pi$ 时：
\begin{equation}
\mathbf{R}((j - i)\theta_m - \pi) = \begin{pmatrix} \cos((j-i)\theta_m - \pi) & -\sin((j-i)\theta_m - \pi) \\ \sin((j-i)\theta_m - \pi) & \cos((j-i)\theta_m - \pi) \end{pmatrix} = -\mathbf{R}((j - i)\theta_m)
\end{equation}
对 $m \in \mathcal{I}_{\text{mob}}$ 求和即得 $-\langle q_i, k_j \rangle_{\mathcal{S}_{\text{mob}}}^{\mathrm{RoPE}}$，完成证明。
\end{proof}

\begin{theorem}[旋转算子的连续 Lipschitz 连续性上界]
\label{thm:lipschitz}
设 $\tilde{\mathbf{R}}_m(t) \triangleq \mathbf{R}(t\theta_m + \Phi_m(t))$ 为子空间 $m$ 上的连续调制旋转算子，记单步有效相位增量为 $\Delta\Phi_m(t+1) \triangleq \Phi_m(t+1) - \Phi_m(t)$，受界于 $|\Delta\Phi_m(t+1)| \le \tilde{\omega}_{\max} \triangleq (1 + 2\eta)\omega_{\max}$。对于满足稳定性条件 $\theta_m + \tilde{\omega}_{\max} \le \pi$ 的相邻位置 $t$ 与 $t+1$，算子差分满足严格谱范数上界：
\begin{equation}
\|\tilde{\mathbf{R}}_m(t+1) - \tilde{\mathbf{R}}_m(t)\|_2 \le 2\sin\left(\frac{\theta_m + \tilde{\omega}_{\max}}{2}\right)
\end{equation}
在标准 RoPE 头中，由于 $\theta_m \le 1.0$ 且 $\tilde{\omega}_{\max} \le \pi - 1 \approx 2.14$，该条件无条件成立。
\end{theorem}
\begin{proof}
对任意平面旋转矩阵 $\mathbf{R}(\alpha), \mathbf{R}(\beta) \in \mathrm{SO}(2)$，提公因式得：
\begin{equation}
\mathbf{R}(\alpha) - \mathbf{R}(\beta) = \mathbf{R}(\beta) \left( \mathbf{R}(\alpha - \beta) - \mathbf{I} \right)
\end{equation}
由于正交矩阵的谱范数为 $\|\mathbf{R}(\beta)\|_2 = 1$，且差分矩阵 $\mathbf{R}(\Delta) - \mathbf{I}$（$\Delta \triangleq \alpha - \beta$）的特征值为 $e^{\pm i \Delta} - 1$，其模长为：
\begin{equation}
|e^{i \Delta} - 1| = \sqrt{(\cos\Delta - 1)^2 + \sin^2\Delta} = \sqrt{2 - 2\cos\Delta} = 2\left|\sin\left(\frac{\Delta}{2}\right)\right|
\end{equation}
由于正规矩阵的谱范数等于其谱半径：
\begin{equation}
\|\mathbf{R}(\alpha) - \mathbf{R}(\beta)\|_2 = 2\left|\sin\left(\frac{\alpha - \beta}{2}\right)\right|
\end{equation}
将 $\alpha = (t+1)\theta_m + \Phi_m(t+1)$ 与 $\beta = t\theta_m + \Phi_m(t)$ 代入，并由中值定理得知 $|f'(\bar{\Phi})| \le 1 + 2\eta$，单步相位增量满足：
\begin{equation}
|\alpha - \beta| = |\theta_m + \Delta\Phi_m(t+1)| \le \theta_m + (1 + 2\eta)|\omega_m(t+1)| \le \theta_m + \tilde{\omega}_{\max} \le \pi
\end{equation}
由正弦函数在 $[0, \pi]$ 上的单调性，即确立了谱范数上界。
\end{proof}

\begin{theorem}[条件成对目标-诱饵优势比衰减定理]
\label{thm:odds_ratio}
设 Query $q_i \in \mathbb{R}^d$ 在单个注意力头内通过 Softmax 聚合历史 Key $l \in \{0, \dots, i\}$。记基准 RoPE 旋转在两子空间上的分量为：
\begin{equation}
A_{il}^{\text{anchor}} \triangleq \frac{1}{\sqrt{d}}\sum_{m\in\mathcal{I}_{\text{anchor}}} (q_i^{(m)})^\top \mathbf{R}\big((l-i)\theta_m\big) k_l^{(m)}, \quad
A_{il}^{\text{mob}} \triangleq \frac{1}{\sqrt{d}}\sum_{m\in\mathcal{I}_{\text{mob}}} (q_i^{(m)})^\top \mathbf{R}\big((l-i)\theta_m\big) k_l^{(m)}
\end{equation}
假定在演化子空间上相干锁相：有效目标 Key $k$ 与 Query $i$ 同相（$\Delta\Phi_{k\to i}^{(m)} \equiv 0 \pmod{2\pi}$），而失效诱饵 Key $j$ 经历统一对径提升（$\Delta\Phi_{j\to i}^{(m)} \equiv \pi \pmod{2\pi}$）。
则在各头内部，全局背景配分函数 $\tilde{Z}_i$ 在成对相对概率比 $\mathrm{Odds}(k:j\mid i) \triangleq P(k\mid i)/P(j\mid i)$ 中\textbf{严格恒等抵消}，满足：
\begin{equation}
\frac{\mathrm{Odds}_{\mathrm{mob}}(k : j \mid i)}{\mathrm{Odds}_{\mathrm{std}}(k : j \mid i)} = \exp\!\left(2 A_{ij}^{\text{mob}}\right), \qquad
\frac{\mathrm{Odds}_{\mathrm{mob}}(j : k \mid i)}{\mathrm{Odds}_{\mathrm{std}}(j : k \mid i)} = \exp\!\left(-2 A_{ij}^{\text{mob}}\right)
\end{equation}
特别地，严格的诱饵优势比衰减（$\mathrm{Odds}_{\mathrm{mob}}(j:k\mid i) < \mathrm{Odds}_{\mathrm{std}}(j:k\mid i)$）当且仅当演化子空间基底内积为正（$A_{ij}^{\text{mob}} > 0$）时成立。
\end{theorem}
\begin{proof}
对任意两个 token $k$ 与 $j$，Softmax 分布下的成对优势比为：
\begin{equation}
\mathrm{Odds}(k : j \mid i) \triangleq \frac{P(k \mid i)}{P(j \mid i)} = \frac{\exp(\tilde{A}_{ik}) / \tilde{Z}_i}{\exp(\tilde{A}_{ij}) / \tilde{Z}_i} = \frac{\exp(\tilde{A}_{ik})}{\exp(\tilde{A}_{ij})} = \exp(\tilde{A}_{ik} - \tilde{A}_{ij})
\end{equation}
配分函数 $\tilde{Z}_i = \sum_{l'=0}^i \exp(\tilde{A}_{il'})$ 在分子分母中无任何近似地严格抵消。

在标准 RoPE 下，未调制 logits 为 $A_{ik}^{\text{std}} = A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}$ 以及 $A_{ij}^{\text{std}} = A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}}$，优势比为：
\begin{equation}
\mathrm{Odds}_{\text{std}}(k : j \mid i) = \exp\left( (A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}) - (A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}}) \right)
\end{equation}
在 SG-M\"obius 调制下，目标 $k$ 同相（$\Delta\Phi_{k \to i} = 0$），logit 保持不变；对诱饵 $j$，由定理~\ref{thm:trans_inv}，反相半周反转演化子空间内积：$\tilde{A}_{ij} = A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}}$。调制后的成对优势比为：
\begin{equation}
\mathrm{Odds}_{\mathrm{mob}}(k : j \mid i) = \exp\left( (A_{ik}^{\text{anchor}} + A_{ik}^{\text{mob}}) - (A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}}) \right)
\end{equation}
两式相除：
\begin{equation}
\frac{\mathrm{Odds}_{\mathrm{mob}}(k : j \mid i)}{\mathrm{Odds}_{\mathrm{std}}(k : j \mid i)} = \frac{\exp(A_{ik}^{\text{std}} - A_{ij}^{\text{anchor}} + A_{ij}^{\text{mob}})}{\exp(A_{ik}^{\text{std}} - A_{ij}^{\text{anchor}} - A_{ij}^{\text{mob}})} = \exp\left( 2 A_{ij}^{\text{mob}} \right)
\end{equation}
取倒数即得诱饵衰减因子 $\exp(-2 A_{ij}^{\text{mob}})$，证毕。
\end{proof}

\begin{corollary}[前缀配分函数收缩与归一化概率质量虹吸推论]
\label{cor:partition_siphoning}
设 $t_2$ 为语篇语义反转触发位置，对所有前置失效历史 token $l < t_2$，相对相移满足 $\Delta\Phi_{l \to i} \in [\pi - \delta, \pi + \delta]$，容差界 $\delta \in [0, \pi/6]$。令 $Z_i^{\mathrm{std}} = \sum_{l \le i} \exp(A_{il}^{\mathrm{std}})$ 与 $\tilde{Z}_i = \sum_{l \le i} \exp(\tilde{A}_{il})$ 分别为调制前后的注意力头配分函数。
若在前置失效区间 $\mathcal{P} \triangleq \{l \mid l < t_2\}$ 上演化子空间内积满足 $A_{il}^{\mathrm{mob}} > 0$，则全局配分函数发生严格收缩：
\begin{equation}
\tilde{Z}_i = Z_i^{\mathrm{std}} - \sum_{l \in \mathcal{P}} \exp(A_{il}^{\mathrm{std}})\left(1 - \exp\big(-2\cos\delta \cdot A_{il}^{\mathrm{mob}}\big)\right) \triangleq Z_i^{\mathrm{std}} - \Delta Z_{\mathcal{P}} < Z_i^{\mathrm{std}}
\end{equation}
因此，分配给下游有效目标指令 $k \ge t_2$ 的绝对 Softmax 注意力概率获得严格放大：
\begin{equation}
\tilde{A}_{ik} = \frac{\exp(A_{ik}^{\mathrm{std}})}{Z_i^{\mathrm{std}} - \Delta Z_{\mathcal{P}}} = A_{ik}^{\mathrm{std}} \cdot \left(\frac{1}{1 - \frac{\Delta Z_{\mathcal{P}}}{Z_i^{\mathrm{std}}}}\right) > A_{ik}^{\mathrm{std}}
\end{equation}
前置失效区间配分函数的收缩将大量归一化概率质量主动虹吸投射至有效新指令上，从理论上解释了为何在 $L=1,116$ 时，多头整体 ACR 增益高达 $+465.1\%$（$3.62 \to 20.44$），远超单点诱饵的物理衰减倍数（$1.62\times$）。
\end{corollary}

\subsection{因果 KV-Cache 不变性与系统工程实现}
在生产部署中，核心要求是必须完全兼容自回归 KV-Cache，绝不追溯重算历史状态。

\begin{proposition}[Prefill 并行计算与自回归 KV-Cache 解码等价性]
\label{prop:kv_cache}
设 $L_{\max}$ 为会话全局上下文预算，参数化时不变锚定比 $\alpha(L_{\max}) \in [0.5, 0.875]$。设 $\mathbf{m}_{\text{sub}} \in \{0, 1\}^{d/2}$ 为静态子空间掩码（$\mathbf{m}_{\text{sub}}[m] = \mathbb{I}(m \in \mathcal{I}_{\text{mob}})$），$\bar{\Phi}(t) = \sum_{\tau=0}^t \omega(\tau)$ 为平滑相位角速度的前缀和，$\Phi(t) = \bar{\Phi}(t) - \eta\sin(2\bar{\Phi}(t))$ 为逐点量化相位。定义调制正交旋转算子直和：
\begin{equation}
\tilde{\mathbf{R}}(t) \triangleq \bigoplus_{m=1}^{d/2} \mathbf{R}\big(t\theta_m + \mathbf{m}_{\text{sub}}[m]\Phi(t)\big) \in \mathrm{SO}(d)
\end{equation}
由于演化子空间边界 $\mathcal{I}_{\text{mob}}$ 由全局预算 $L_{\max}$ 静态锚定，自回归生成过程中已缓存的键向量绝不会遭受子空间维度动态漂移。对于任意长度 $L \le L_{\max}$，在批处理并行 Prefill 阶段计算的注意力矩阵：
\begin{align}
A_{\mathrm{prefill}}[i, j] &= \frac{1}{\sqrt{d}} \sum_{m=1}^{d/2} \left( \mathbf{R}(i\theta_m + \mathbf{m}_{\text{sub}}[m]\Phi(i)) q_{i,m} \right)^\top \left( \mathbf{R}(j\theta_m + \mathbf{m}_{\text{sub}}[m]\Phi(j)) k_{j,m} \right) \nonumber \\
&= \frac{1}{\sqrt{d}} \left( \tilde{\mathbf{R}}(i) q_i \right)^\top \left( \tilde{\mathbf{R}}(j) k_j \right)
\end{align}
与自回归单步解码时使用已缓存 Key $\mathbf{K}_{\mathrm{cache}}[j] = \tilde{\mathbf{R}}(j) k_j$ 计算的 logits：
\begin{equation}
A_{\mathrm{decode}}[i, j] = \frac{1}{\sqrt{d}} \tilde{q}_i^\top \mathbf{K}_{\mathrm{cache}}[j] \equiv A_{\mathrm{prefill}}[i, j], \qquad \forall 0 \le j \le i < L
\end{equation}
在代数上严格等价，最大数值漂移严格受浮点舍入约束（$< 10^{-12}$）。特别地，已缓存的历史键向量 $\mathbf{K}_{\mathrm{cache}}[j]$ 在未来的时间步 $i > j$ 保持\textbf{严格不可变}。
\end{proposition}
\begin{proof}
缓存 Key $\mathbf{K}_{\mathrm{cache}}[j] = \tilde{\mathbf{R}}(j) k_j$ 仅严格依赖时间戳 $\tau \le j$ 的历史输入隐状态 $h_\tau$ 与会话时不变截止比 $\alpha(L_{\max})$。因为前缀和与逐点投影完全满足因果性，未来的相位角速度 $\omega(\tau)$（$\tau > j$）绝不影响 $\Phi(j)$。在解码步 $i \ge j$ 时，Query 向量 $\tilde{q}_i = \tilde{\mathbf{R}}(i) q_i$ 直接与显存中不可变的已缓存向量 $\mathbf{K}_{\mathrm{cache}}[j]$ 执行点积。由矩阵乘法结合律，结果与 Prefill 阶段完全吻合，无需任何追溯性 Cache 重写。
\end{proof}

\begin{proposition}[两阶段并行关联扫描与 Higham FP16 数值稳定性界]
\label{prop:associative_scan}
设 $H = (h_0, h_1, \dots, h_{L-1}) \in \mathbb{R}^{L \times d}$ 为 Prefill 隐状态序列。因果相位流 $\Phi \in \mathbb{R}^L$ 通过两阶段并行关联扫描计算：
\begin{enumerate}
    \item \textbf{第一阶段（仿射 EMA 扫描）}：令 $g_t = \omega_{\max} \cdot \mathrm{softsign}(\mathrm{ReLU}(|z_t| - \tau_{\text{gate}})\mathrm{sgn}(z_t))$。带有初始边界 $\omega_{-1}=0$ 的 IIR 滤波器 $\omega_t = (1-\nu)\omega_{t-1} + \nu g_t$ 等价于在结合二元算子 $(a_2, b_2) \otimes (a_1, b_1) = (a_2 a_1, \, a_2 b_1 + b_2)$ 下对仿射变换元 $(a_t, b_t) = (1-\nu, \, \nu g_t)$ 求前缀规约，并行深度为 $\mathcal{O}(\log L)$。
    \item \textbf{第二阶段（加法前缀和扫描）}：以 $\bar{\Phi}_{-1}=0$ 为边界，累积未约束相位 $\bar{\Phi}_t = \sum_{\tau=0}^t \omega_\tau$ 通过标准实数加法群 $(\mathbb{R}, +)$ 下的并行前缀和求取。
    \item \textbf{第三阶段（逐点锁相量化）}：$\Phi_t = \bar{\Phi}_t - \eta\sin(2\bar{\Phi}_t)$ 以 $\mathcal{O}(1)$ 深度逐点执行。
\end{enumerate}
在 IEEE 754 半精度（FP16）浮点运算下（机器单位舍入误差 $u = 2^{-11} \approx 4.88 \times 10^{-4}$），树状扫描深度 $D = \lceil \log_2 L \rceil$ 累积的前向浮点误差满足解析界：
\begin{equation}
|\mathrm{fl}(\bar{\Phi}_L) - \bar{\Phi}_L| \le D \cdot u \cdot M_\Phi + \mathcal{O}(u^2)
\end{equation}
其中 $M_\Phi \triangleq \sum_{\tau=0}^{L-1} |\omega_\tau| = K\pi$ 代表 $K$ 次叙事反转跨度的相位总变差。对于至多 $K = 10$ 次反转（$M_\Phi \le 10\pi$）且 $L \le 18,030$（$D = 15$），最大累积浮点漂移被严格约束在：
\begin{equation}
|\Delta \bar{\Phi}_L| \le 15 \times (4.88 \times 10^{-4}) \times (10\pi) \approx 0.230\,\text{rad} \approx 13.2^\circ < \frac{\pi}{6}
\end{equation}
因为 $|\Delta \bar{\Phi}_L| < \frac{\pi}{6}$，数值漂移严格落在周期势能 $V(\bar{\Phi}) = -\frac{\eta}{2}\cos(2\bar{\Phi})$ 的非平凡吸引势阱内，锁相量化器可自动熄灭浮点漂移，杜绝偶发符号翻转。
\end{proposition}

\paragraph{尾部角度融合（Epilogue Angle Fusion）系统实现。}
在批量 Prefill 阶段（$L \gg 1$），我们在标量维度并行计算相位角速度投影并执行两阶段并行关联扫描（命题~\ref{prop:associative_scan}）；在单步自回归解码阶段，我们将标量角速度投影 $g_h(h_t)$、$O(1)$ 递推与子空间掩码角度偏移：
\begin{equation}
\tilde{\Theta}_{h,t} = t\Theta + \Phi_h(t)\mathbf{m}_{\text{sub}}, \quad \mathbf{m}_{\text{sub}} \in \{0, 1\}^{d/2}
\end{equation}
直接融合进 QKV 投影的尾部（Epilogue），在启动旋转核函数时一并生效。因此，核心的 Query-Key GEMM 访存模式和计算图与标准 RoPE 完全一致，解码时延保持完美的 $O(1)$。

\begin{algorithm}[htbp]
\caption{带有子空间反相 KV-Cache 的自回归生成算法}
\label{alg:kv_decoding}
\begin{algorithmic}[1]
\STATE \textbf{初始化：} 边界状态 $\omega_{-1} \gets 0$，累积未约束相位 $\bar{\Phi}_{-1} \gets 0$，子空间掩码 $\mathbf{m}_{\text{sub}} \in \{0, 1\}^{d/2}$（$\mathbf{m}_{\text{sub}}[m] = \mathbb{I}(m \in \mathcal{I}_{\text{mob}})$），缓存 $\mathbf{K} \gets [], \mathbf{V} \gets []$。
\FOR{每个解码步 $i = 0, 1, 2, \dots$}
     \STATE 接收层隐状态 $h_i \in \mathbb{R}^d$，计算基底投影 $q_i, k_i, v_i$。
     \STATE 计算死区连续相位角速度投影 $g_i \gets \omega_{\max} \cdot \mathrm{softsign}\big(\mathrm{ReLU}(|w_g^\top h_i + b_g| - \tau_{\text{gate}})\mathrm{sgn}(w_g^\top h_i + b_g)\big)$。
     \STATE 更新平滑角速度：$\omega_i \gets (1 - \nu)\omega_{i-1} + \nu g_i$。
     \STATE 更新累积未约束相位：$\bar{\Phi}_i \gets \bar{\Phi}_{i-1} + \omega_i$。
     \STATE 应用免训练锁相量化器：$\Phi_i \gets \bar{\Phi}_i - \eta \sin(2\bar{\Phi}_i)$。
     \STATE 构造调制旋转矩阵：$\tilde{\mathbf{R}}(i) \triangleq \bigoplus_{m=1}^{d/2} \mathbf{R}(i\theta_m + \mathbf{m}_{\text{sub}}[m]\Phi_i)$。
     \STATE 调制 Key 向量：$\tilde{k}_i \gets \tilde{\mathbf{R}}(i) k_i$。
     \STATE 追加至 KV-Cache：$\mathbf{K} \gets [\mathbf{K}; \, \tilde{k}_i]$，$\mathbf{V} \gets [\mathbf{V}; \, v_i]$ \COMMENT{历史缓存零追溯修改}
     \STATE 调制 Query 向量：$\tilde{q}_i \gets \tilde{\mathbf{R}}(i) q_i$。
     \STATE 计算因果注意力：$\mathbf{a}_i \gets \mathrm{Softmax}\left( \frac{\tilde{q}_i^\top \mathbf{K}}{\sqrt{d}} \right)$，$\mathbf{o}_i \gets \mathbf{a}_i \mathbf{V}$。
\ENDFOR
\end{algorithmic}
\end{algorithm}

\section{形式化机器证明与性质验证}
为了排除潜在的数学不一致与失效隐患，我们在两个独立的验证框架下形式化证明了核心代数不变量与算法等价性：

\paragraph{Lean~4 交互式定理证明。}
在 \texttt{formal\_verification/MobiusAttention.lean} 中，我们使用 Lean~4 交互式定理证明器 \cite{moura2021lean} 形式化了离散因果序列、两阶段并行关联扫描前缀求和与子空间反相旋转。在\textbf{零自定义公理、零 \texttt{sorry}} 的严格前提下证明了 5 大核心定理：
\begin{itemize}
    \item \emph{基线退化}（\texttt{conservation\_of\_flatness}）：$\forall t, \omega(t) = 0 \implies \mathbf{R}_{\text{mod}}(t) = \mathbf{R}(t\theta)$（中性语篇严格退化为标准 RoPE，无任何修改）。
    \item \emph{前缀和可加性}（\texttt{holonomy\_path\_additivity}）：$\forall j \le k \le i, \Delta\Phi(j, i) = \Delta\Phi(j, k) + \Delta\Phi(k, i)$（严格满足并行关联扫描的因果区间前缀和结合律分解）。
    \item \emph{对径反相}（\texttt{antipodal\_inversion}）：$\Delta\Phi(j, i) = \pi \implies \mathrm{ParityFactor} = -1$（半周旋转在子空间内积上产生严格反相相消符号反转）。
    \item \emph{循环宇称守恒}（\texttt{cyclic\_parity\_conservation}）：$\Delta\Phi(j, i) = 2\pi \implies \mathrm{ParityFactor} = +1$（双重否定完全恢复同相旋转）。
    \item \emph{相移平移不变性}（\texttt{gauge\_translation\_invariance}）：$\forall \Phi_i, \Phi_j, c \in \mathbb{R}, (\Phi_i + c) - (\Phi_j + c) = \Phi_i - \Phi_j$（全局固定相移在相对成对内积计算中恒等消去）。
\end{itemize}
\emph{形式化证明边界披露}：为恪守学术严密性，我们在此明确形式化范畴的边界：Lean~4 机器证明所确立的是无界实数域 $\mathbb{R}$ 上的群论对称性与三角代数恒等式。与之互补，有限精度 FP16 浮点稳定性（命题~\ref{prop:associative_scan} 中的 $D \cdot u \cdot M_\Phi \le 0.230 < \pi/6$）以及自适应截止比 $\alpha(L_{\max})$ 的动态行为则通过 Z3 SMT 求解器、Hypothesis 属性测试与物理多 GPU 实验进行严格约束。

\paragraph{Z3 SMT 求解器与极限长度模糊测试。}
在 \texttt{formal\_verification/verify\_properties.py} 中，我们调用 Z3 SMT 求解器 \cite{de2008z3} 证明了在无界实数域上前缀和可加性、相移平移不变性与相位流因式分解的反命题均为严格的 \texttt{UNSAT}。此外，我们形式化验证了旋转算子的连续 Lipschitz 连续性上界（定理~\ref{thm:lipschitz}）以及 Prefill 与自回归 KV-Cache 解码的代数等价性（命题~\ref{prop:kv_cache}）。在 4 个长度区间（$L \in [10, 512]$、$[512, 2048]$、$ [2048, 8192]$、$[8192, 32768]$）并带有至多 50 层嵌套反转的 2,000 组极端随机序列模糊测试中：
\begin{itemize}
    \item 32,768 步累积相位的最大数值漂移仅为 $1.14 \times 10^{-13}$（远低于机器精度）。
    \item 对偶调制保模长误差为 $0.00 \times 10^0$（绝对保距，对比单侧非对称调制的 37.17 最大误差）。
    \item 2,000 组自动化测试全部通过（\textbf{100.0\% 通过率}）。
\end{itemize}

\section{实验评估 (Experiments)}
\paragraph{实验环境。}
所有实证评测均在原生 \textbf{Qwen3.5-9B} 模型 \cite{qwen35} 上完成，运行于双卡 Nvidia Tesla T4 GPU（原生 FP16），显存分配分别为 GPU 0 占用 7.19\,GB、GPU 1 占用 10.34\,GB（合计 17.53\,GB）。

\subsection{多尺度长上下文失效基准 ($L \in [545, 18030]$)}
我们在双卡 T4 上将序列长度自 $L=545$ 扩展至 $18,030$ tokens。在 $t_1 = 28$ 处放置已失效的“诱饵”指令，在 $t_2 \approx L/2$ 处放置推翻前述指令的“目标”指令。在句尾探针 $i = L-1$ 处测得：
\begin{itemize}
    \item \textbf{诱饵注意力（$A_{\mathrm{decoy}}$）}：多头平均分配给失效诱饵的 Softmax 概率；
    \item \textbf{目标注意力（$A_{\mathrm{target}}$）}：多头平均分配给有效目标的 Softmax 概率；
    \item \textbf{注意力对比度（ACR）}：$\mathrm{ACR} \triangleq A_{\mathrm{target}} / (A_{\mathrm{decoy}} + \epsilon)$；
    \item \textbf{诱饵压制比}：$A_{\mathrm{decoy}}^{\mathrm{std}} / A_{\mathrm{decoy}}^{\mathrm{mob}}$；
    \item \textbf{中性困惑度（PPL）}：在 WikiText-103 中性文本上的困惑度。
\end{itemize}

如表~\ref{tab:benchmark} 所示，标准 RoPE 在所有长度下均向失效前提持续泄漏注意力。
而在我们提出的自适应截止防御 $\alpha(L)$ 机制下，SG-M\"obius 在所评测的所有上下文长度（$L \in [545, 18030]$）上均实现了对失效诱饵注意力的一致严格物理压制（压制比在 $1.13\times\sim 1.90\times$ 之间，全程稳定高于 $1.0\times$ 基线），并在全序列尺度上驱动了大幅度的注意力对比度（ACR）提升。特别是在 $L=1,116$ 时，多头 ACR 相对基线暴增 $+465.1\%$（由 $3.62\to 20.44$，诱饵注意力自 $1.09\times 10^{-3}$ 剧降至 $6.76\times 10^{-4}$）；在 $L=4,480$ 时 ACR 提升 $+228.8\%$（$2.06\to 6.78$）；在 $L=18,030$ 极限尺度下，诱饵注意力被有效压制 $1.34\times$（$2.23\times 10^{-4} \to 1.67\times 10^{-4}$），驱动多头 ACR 提升 $+88.5\%$（$1.31\to 2.48$），并在特定检索单头（Layer~7, Head~4）上达到了高达 $16.4\times$ 的峰值优势比放大。

\paragraph{固定锚定比（$\alpha=0.50$）消融分析与载波反向混叠理论验证。}
为了实证检验定理~\ref{thm:odds_ratio} 预测的理论相位边界，我们进一步评估了采用固定静态截止 $\alpha=0.50$ 的未设防消融变体。在该基线消融中，在中间 token 距离 $i - j \in [10^3, 2.3 \times 10^3]$（$L=1,116$ 与 $L=2,250$）时，部分中频旋转通道相干进入第一负半周（$\pi/2 < (i-j)\theta_m < 3\pi/2$，$\cos((i-j)\theta_m) < 0$），导致演化子空间基底内积变为负值（$A_{ij}^{\text{mob}} < 0$）；此时施加 $\pi$ 相移将负内积反转为正值，使得未设防时的诱饵压制比一度回落至 $1.0$ 以下（$L=1,116$ 时为 $0.67\times$；$L=2,250$ 时为 $0.60\times$）。而在超长尺度（$L \ge 4,480$）下，中频通道沿通道索引 $m$ 发生剧烈相消退相干（$\sum_{m \in \mathcal{I}_{\text{mid}}} \cos((i-j)\theta_m) \approx 0$），压制效果自然恢复（$1.14\times\sim 2.33\times$）。动态自适应截止比 $\alpha(L) = \min\left(0.875, \, \max\left(0.5, \, \frac{\ln(2L/\pi)}{\ln \theta_{\mathrm{base}}}\right)\right)$ 通过将易混叠通道动态冻结至恒等句法锚点子空间，彻底消除了该局限性，在所有尺度上彻底消除了低于 $1.0\times$ 的倒挂隐患，恢复了稳定大于 1.0 倍的诱饵物理压制（$1.62\times$ 与 $1.17\times$），证实了自适应频谱滤波对任意上下文尺度的全面防御能力。

\section{结论与局限性 (Conclusion and Limitations)}
本文提出了子空间反相注意力（Subspace Anti-Phase Attention, SG-M\"obius-RoPE），通过因果正交子空间分解 $\mathbb{R}^d = \mathcal{S}_{\text{anchor}} \oplus \mathcal{S}_{\text{mob}}$ 扩展了旋转位置编码（RoPE）。其核心思想借鉴主动降噪（ANC）的声波反相相消原理：锚定子空间保留长程拓扑因果序，而演化子空间通过两阶段并行关联扫描累积连续相位角速度，并在否定处实施 $\pi$ 相移的主动反相相消干涉（$\mathbf{R}(\theta - \pi) = -\mathbf{R}(\theta)$），在双重否定处实现同相复原（$\Delta\Phi = 2\pi$）。核心代数性质在 Lean~4 与 Z3 SMT 中完成严格形式化机器证明。在真实 Qwen3.5-9B 模型（双卡 Tesla T4，FP16）的实测中，取得了全尺度稳定大于 1.0 倍的诱饵物理压制（$1.13\times\sim 1.90\times$，全程大于 $1.0\times$）与最高 $+465.1\%$ 的多头 ACR 提升，单头（Layer~7, Head~4）最高实现 $16.4\times$ 优势比放大，且完全兼容尾部融合的 $\mathcal{O}(1)$ KV-Cache 增量解码与零困惑度退化。

\paragraph{局限性与未来工作。}
当前实现采用一维粘性平滑与有界连续相位角速度投影 $|\omega(t)| \le \omega_{\max}$。对于高度歧义或专业领域语料，语义投影头可能需要任务微调。未来极具潜力的研究方向包括：在基础模型预训练阶段进行端到端可微相位投影学习，使连续相位场在各注意力头间联合优化；以及将子空间反相调制动力学推广至多维视觉（2D ViT）与视频时空注意力架构。
